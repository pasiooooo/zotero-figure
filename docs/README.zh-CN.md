# PDF Figure (pasiooooo)

在 Zotero 中提取 PDF 里的图、表和公式。

本分支基于 [MuiseDestiny/zotero-figure](https://github.com/MuiseDestiny/zotero-figure)。完整改动见[更新日志](../CHANGELOG.md)，标签自动发布流程见[发布说明](RELEASING.md)。

**从原插件或本分支 1.1.0 升级：** 请先停用旧插件，手动安装一次 1.1.1 或更新版本，然后重启 Zotero。新插件 ID 为 `zotero-figure@pasiooooo.github.io`，无法跨 ID 自动更新。首次启动会把旧解析结果、对比布局、模型和设置复制到独立目录，保留原数据；请预留复制所需的磁盘空间，并在首次迁移时保持旧插件停用。此后两个插件的数据独立保存。

Zotero Figure 可检测 PDF 中的图、表、独立公式、说明和表格脚注。PDF 读取、渲染和版面检测均在本机完成，所需模型已内置在插件中。

## 功能

- 在本机分析 PDF，不上传页面，也不在运行时下载模型。
- 在阅读器专用侧栏中查看结果、组合选择有结果的类型筛选，并跟踪分析进度。
- 复制、保存或贴出图片，修改说明，或在按 PDF 页面比例调整的窗口中校正裁图区域；跳转到 PDF 页面，添加到笔记或删除结果。
- 在 PDF 阅读器中右键选中的图片标注，可将其添加到本地图表解析结果；已有的 Figure、Table 或 Formula 标签会保留。
- 在“PDF 图表库”中集中浏览多篇文献的结果，并按文献、年份、分类、类型和说明关键词筛选。可在自动记忆的瀑布流与文献分栏间切换；在文献分栏中按稳定页码顺序显示结果，并对齐到可选命名的对比行。拖动文献表头可调整列顺序，拖动同一文献中的图片卡片可调整行位置，也可右键图片将其加入对比分组。同一文献在一个分组中包含多张图片时，单元格会显示主图和左侧缩略图；点击缩略图即可将其切换为主图。解散分组可删除对应的对比行，工具栏缩放控件可统一调整全部预览大小。
- 对比布局保存在 Zotero 数据目录内的 `zotero-figure-pasiooooo/comparison-layouts.json`，支持大型对比表。旧布局会自动迁移；备份时请包含此文件。布局不通过 Zotero Sync 同步。
- 批量分析选中的文献条目或 PDF 附件，并可将结果写入笔记或 Zotero 标注。
- 安装 Zotero PDF Translate 后翻译结果说明。
- 可选通过 SiliconFlow `Qwen/Qwen3.6-35B-A3B` 识别公式 LaTeX，在本机使用 KaTeX 渲染，并可复制、重新识别，或通过 CodeMirror 源码编辑器和 KaTeX 实时预览修改源码。
- 创建带嵌入式 PNG 的 Zotero 笔记，点击图片可返回源 PDF。
- 可选将本地结果镜像为 Zotero 图片标注，以便同步和兼容其他插件。
- 界面支持英语、简体中文、意大利语和俄语。

## 环境要求

- Zotero 9 或 Zotero 10。
- [最新版本](https://github.com/pasiooooo/zotero-figure/releases/latest)中的 Zotero Figure XPI。
- 仅公式 OCR 需要网络连接和 SiliconFlow API 密钥。

不需要 Java 或 `pdffigures2.jar`。

## 安装

1. 从最新 Release 下载 `zotero-figure.xpi`。
2. 在 Zotero 中打开“工具 > 插件”，选择“从文件安装插件”，然后选择 XPI。
3. 如果 Zotero 提示，请重启应用。

## 功能入口

- **PDF 阅读器：** 打开 PDF，点击左侧栏中的 Zotero Figure 图标，再选择“解析图、表和公式”。
- **侧栏浏览：** 双击图注即可修改，无图注的结果也可双击补充，输入区随编辑窗口伸缩。无图注或图注无编号的结果排在最前面；有编号的图片、表格、公式按类型分组，再按完整编号自然排序，支持 `1.2`、`1-10` 等编号。点击侧栏顶部左起第二个按钮，打开最大化 Library，默认选中当前文献并收起底部悬浮栏。窗口沿用主 Library 的视图模式和完整结果，展开悬浮栏后可自由切换文献或清除初始筛选，Type 等其他筛选也照常可用。
- **区域补识别：** 点击 Figure 侧栏的“框选区域识别”，立即进入截图式选区界面；在 PDF 单页内拖动框选，松开后识别，Esc 或右键取消。有图注时可一并框入。图、表缺少图注时，会额外检测一次本页来补充图注上下文，不导入框外图表。图注文字取自 PDF 文本层，扫描图注暂不进行 OCR。区域识别只保存本地结果，不创建 Zotero 批注。已有结果卡片也可右键“重新识别此区域”。仅替换完全落在框内的旧结果，框外结果不变；未检出内容时保留原结果。
- **自动分析新 PDF：** 在设置 → 其它中开启“自动分析新添加的 PDF”（默认关闭）。仅处理启用后的新增 PDF，逐份排队，跳过已解析结果；文件未下载时最多等待约五分钟。关闭选项会取消自动任务并清空队列。批注同步及付费公式识别仍遵循各自的独立开关。
- **图表库：** 点击主窗口工具栏中搜索框左侧的 PDF 图表库图标，在独立最大化窗口中集中浏览不同文献的结果；底部工具栏默认收起，重复点击会聚焦已有窗口。双击卡片可打开源 PDF。
- **图表库筛选：** 分类与文献按钮打开同一个浏览面板，按 Zotero 集合层级显示分类，并支持按文献标题检索。选择父集合会包含子集合，切换集合会清除当前文献限制。年份可输入单年或包含首尾的范围（如 `2020–2024`），也可点击按年统计结果数量的柱形图；无年份文献在“全部年份”下保留。图片、表格、公式通过图标筛选，再次点击已选图标或“全部类型”按钮可恢复全部类型。侧栏最大化窗口使用同一套控件。
- **框选纠正图注：** 在结果的右键菜单选择“纠正图注”，框选正确图注，松开后从 PDF 文本层本地提取并替换这条结果的说明，同时更新排序并定位结果。无需下载模型或调用付费接口；无文本层的扫描页需要 OCR，选区无文字时保留原图注。
- **图表库缩放：** 按住 Ctrl（Windows/Linux）或 Command（macOS）滚动鼠标滚轮，按滚动幅度连续调整；`+`/`-` 按比例缩放，`0` 恢复 100%。滑块及百分比输入框支持 1% 精度，范围为 10%–1000%。每帧合并更新，停止缩放后再调整瀑布流列数，最大化 Library 窗口同样适用。
- **批量处理：** 在文库中选中文献条目或 PDF 附件，右键打开 `PDF Figure (pasiooooo) >`，可进行分析、写入笔记或创建标注。选中图片标注后选择“添加到 Figure”即可批量导入。
  开始前会列出已有解析记录的 PDF，可选择重新分析并覆盖、跳过这些 PDF 并继续处理其余文件，或取消整批任务。解析成功但未找到结果的 PDF 也会记为已解析。
- **设置：** 打开 PDF Figure 设置页，可管理内置模型、标注同步和 SiliconFlow 公式 OCR，也可直接打开图表库；使用“转换已有公式”可处理所有文库中尚未缓存的公式。

## 隐私

PDF 解析、渲染、版面检测和本地结果存储均留在当前设备。除非开启标注镜像，本地结果不会使用 Zotero Sync。

公式 OCR 为可选功能。检查 API 密钥只会向 SiliconFlow 发送纯文本请求；识别公式时只发送公式 PNG 裁图，不会发送整页 PDF。密钥保存在本机 Zotero 偏好设置中，SiliconFlow 调用可能产生费用。
